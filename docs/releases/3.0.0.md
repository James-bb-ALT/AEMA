# AEMA 3.0.0 — 25/11/2026

Nova etapa de release, conforme a classificação do proprietário: previsão leve offline.
App, pacote Python e documentação avançam para 3.0.0; app versionCode 30000.

- Ridge nativo para as próximas seis horas: tela, CPU, Wi-Fi, rede móvel e 1–12 UIDs.
- Treino no computador, validação/teste cronológicos, JSON FP32 e importação local atômica.
- Janelas verificadas por par, oito válidas em até 14 dias, sem preencher lacunas.
- Demonstração sintética independente, rankings separados, sugestões locais e debug.
- Tentativa automática após coleta; previsão pessoal válida preservada em ZIP com modelo.
- APK padrão assinado sem pesos Qwen; a leitura LLM permanece opcional e importável.
- Manifesto de captura 1.0 recebe boot count aditivo. Contratos novos de modelo/resultado 1.0;
  schemas anteriores, catálogo 1.2 e versões de dependências preservados.

Verificação: 248 testes Python (92,94% cobertura), três testes JVM do motor, cinco
instrumentados Android e lint sem erros (35 avisos). Simulação: 96 capturas sintéticas,
87 exemplos, MAE 22,1647 mAh vs baseline 23,2052; paridade host/Java em 16 casos.

O APK tem 98.442.636 bytes e ainda inclui Python/pandas. Não há validação de precisão,
energia ou economia em telefone físico. Modelo pessoal exige dados elegíveis e treino;
a demonstração não é uma previsão do usuário. Não há atualização automática de pesos.
