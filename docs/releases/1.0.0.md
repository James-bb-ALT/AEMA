# AEMA 1.0.0

Primeira release do app Android de coleta local com Shizuku. Esta é uma nova etapa
de release na classificação do usuário, por incluir novas funcionalidades e um novo app.
Pacote Python e versão exposta em runtime também passam para 1.0.0.

## Instalação e uso

Baixe `AEMA-1.0.0.apk`, instale e inicie Shizuku. No AEMA, autorize o acesso, escolha uma
pasta local, permita alarmes/notificações e ative a coleta de seis horas. A primeira coleta
começa imediatamente. Transfira os ZIPs da pasta escolhida ao computador posteriormente.

O APK é assinado com chave persistente mantida fora do repositório. A release inclui hash
SHA-256 e o pacote Python wheel; chaves e dumps privados não são publicados.

## Comportamento

Cada execução salva os arquivos brutos, metadados e hashes; quando o formato é suportado,
inclui as tabelas canônicas processadas com o mesmo núcleo Python do host. Cada captura
tem arquivo próprio. Erros de coleta e formato não são apresentados como medições válidas.
Não há permissão de internet. Backup/transferência automática de dados do app estão desativados.

Privacidade inclui cópia privada no app e exportação pseudonimizada no computador via
`aema pseudonymize`. ZIPs brutos continuam privados. Não confundir pseudonimização com anonimato.

## Verificação e limites

Consulte [a matriz de compatibilidade](../android/COMPATIBILITY.md) para as evidências
executadas. Testes de software não validam precisão elétrica nem comportamento de fabricantes.
Shizuku precisa estar ativo; telefone desligado, forçar parada e restrições do Android podem
interromper a automação. Snapshots são acumulados e não representam automaticamente consumo
exclusivo das últimas seis horas. ARM32 e x86 de 32 bits não são incluídos.

Os estudos com referência externa, sincronização, overhead e meta de 1 µA continuam pendentes.
